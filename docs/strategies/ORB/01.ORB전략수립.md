# 01. ORB 전략 수립

작성일: 2026-03-07

## 1. 가설에 필요한 구체화 항목

아래 항목들을 하나씩 숫자와 규칙으로 확정해야 한다.

- [x] 현재 단계에서는 백테스트 조건의 수를 줄이기보다 조건 정의를 최대한 명확하게 쌓는 데 집중
- [x] 조건 수가 많아지더라도 우선 전부 정의하고, 이후 백테스트 결과를 바탕으로 우선순위를 나누어 유지/제거 여부를 결정
- [x] 파라미터는 `핵심 파라미터`와 `보조 파라미터`로 구분하여 관리
- [x] 핵심 파라미터는 초기 백테스트에서 우선 비교하고, 보조 파라미터는 후순위 비교 또는 고정값 처리 대상으로 관리

### 1.1 시장 상태 필터

- KOSPI200 방향성 반영 여부
- 시장 breadth 반영 여부
- 섹터 동조 여부 반영 여부
- Risk-On / Risk-Off 판별 규칙
- 시장 약세일 때 전략 중단 여부

### 1.2 종목 필터

- 보통주만 포함할지
- ETF/ETN/SPAC 제외 여부
- 갭 상승률 범위
- 과도한 갭/초기 과열 종목 제외 여부
- 최소 거래대금
- 최소 거래량 또는 상대 거래량
- 최대 스프레드
- 시가총액 또는 유동주식수 조건 포함 여부

#### 1.2.1 갭 상승률 범위 정의

- [x] 갭 상승률은 단일 하한값이 아니라 `최소값 / 최대값` 범위 파라미터로 관리
- [x] `5%` 갭과 `20%` 갭은 동일한 구조로 보지 않고 별도 구간으로 비교
- [x] 1차 백테스트 비교 구간은 `5% ~ 10%`, `10% ~ 15%`, `15% 이상` 3개 구간으로 우선 확정
- [x] `5% 미만` 갭은 1차 비교 대상에서 제외
- [x] `5% 이상`은 강한 갭 후보군으로 분류
- [x] `7% 이상`은 과열 가능성이 높으므로 별도 그룹으로 성과를 분리 비교
- [x] `20% 이상`은 일반 갭상승 종목보다 이벤트성 급등 종목으로 보고 별도 성과군 또는 제외군으로 검토
- [x] 백테스트에서는 `gap_pct >= x` 단일 조건보다 `min_gap_pct <= gap_pct <= max_gap_pct` 범위 조건을 기본 형태로 사용

#### 1.2.2 오프닝 거래량 필터 정의

- [x] 오프닝 거래량은 절대 거래량보다 `최근 20거래일 동일 시간 구간 평균 거래량 대비 비율`로 비교
- [x] 동일 시간 구간은 선택한 ORB 길이와 동일하게 맞춤
- [x] `5분 ORB`는 최근 20거래일의 `09:00~09:05` 거래량 합계 평균과 비교
- [x] `10분 ORB`는 최근 20거래일의 `09:00~09:10` 거래량 합계 평균과 비교
- [x] 당일 데이터는 평균 계산에서 제외하고, 직전 `20거래일` 기준으로 계산
- [x] 계산식은 `opening_volume_ratio = 오늘 오프닝 구간 거래량 / 최근 20거래일 동일 구간 평균 거래량`
- [x] 오프닝 거래량 필터는 단일 하한값이 아니라 `최소값 / 최대값` 범위 파라미터로 관리
- [x] 1차 백테스트 비교 구간은 `1.5배 ~ 2.0배`, `2.0배 ~ 3.0배`, `3.0배 ~ 5.0배`, `5.0배 이상`으로 우선 확정
- [x] `2.0배 이상`은 유의미한 오프닝 거래량 증가 후보군으로 간주
- [x] `5.0배 이상`은 과열 가능성이 높으므로 별도 성과군 또는 제외군으로 비교 검토
- [x] 평균 왜곡 가능성을 고려하여 2차 비교 단계에서는 평균 외에 중앙값 기준도 별도 검토

### 1.3 ORB 신호 계산 규칙

- [x] ORB 길이: `3분 / 5분 / 10분 / 15분` 4개 비교 대상으로 고정
- [x] ORB 측정 구간의 시작/종료 시각 정의: `09:00`부터 시작하는 첫 N개 1분봉으로 측정하고, 개장 시가는 첫 1분봉에 포함하되 별도 독립 봉으로는 보지 않음
- [x] ORB High 정의: 측정 구간 내 `체결가 기준 최고가`로 정의하고, 1분봉 백테스트에서는 해당 구간 각 1분봉 `High` 값의 최댓값으로 계산
- [x] ORB Low 정의: 측정 구간 내 `체결가 기준 최저가`로 정의하고, 1분봉 백테스트에서는 해당 구간 각 1분봉 `Low` 값의 최솟값으로 계산
- [x] ORB High/Low 산출 기준: `체결가 기반 OHLC`를 사용하며, 호가 기준 고가/저가나 중간값은 사용하지 않음
- [x] 돌파 이벤트 판단 단위: `틱 기준 체결 발생`으로 판단
- [x] 돌파 이벤트 정의: Long 기준 `최초 체결가가 ORB High를 상향 초과한 순간`으로 정의
- [x] 돌파 이벤트 기록 방식: 최초 돌파 시각, 최초 돌파 가격, `최초 돌파 가격 - ORB High` 초과폭을 기본 기록 항목으로 사용

### 1.4 ORB 신호 품질 필터

#### 1.4.1 ORB 형성 강도

- [x] ORB 종료 시 종가 위치: `(ORB 종료 시 종가 - ORB Low) / (ORB High - ORB Low)`로 계산하며, ORB 범위 내에서 종가가 어디에 위치하는지 정규화된 비율로 판단
- [x] ORB 종료 시 종가 위치 비교 후보값: `0.6 / 0.7 / 0.8`
- [x] ORB 종료 시 종가 위치는 `핵심 파라미터`로 취급

- [x] 양봉/음봉 개수: 측정 구간 내 양봉과 음봉의 개수를 집계하여 초기 방향성 강도를 확인
- [x] 양봉 비율: `양봉 수 / 전체 봉 수`로 계산하며, ORB 길이가 달라도 비교 가능하도록 정규화된 비율로 판단
- [x] 양봉 비율 비교 후보값: `0.6 / 0.7 / 0.8`
- [x] 양봉 비율은 `핵심 파라미터`로 취급

- [x] ORB 시작가 대비 종료가 변화율: `((ORB 종료 시 종가 - ORB 시작가) / ORB 시작가)`로 계산하며, ORB 형성 동안 시가 대비 순방향 이동이 실제로 있었는지 판단
- [x] ORB 시작가 대비 종료가 변화율 비교 후보값: `0.0% / 0.3% / 0.5%`
- [x] ORB 시작가 대비 종료가 변화율은 `보조 파라미터`로 취급

- [x] ORB 내부 몸통 비중: `ORB 구간 내 각 봉의 |종가 - 시가| 합 / 각 봉의 (고가 - 저가) 합`으로 계산하며, 꼬리보다 몸통 위주로 형성된 구간인지 판단
- [x] ORB 내부 몸통 비중 비교 후보값: `0.4 / 0.5 / 0.6`
- [x] ORB 내부 몸통 비중은 `보조 파라미터`로 취급

- [x] 윗꼬리/아랫꼬리 구조: 1분봉 OHLC 기준으로 `윗꼬리 = 고가 - max(시가, 종가)`, `아랫꼬리 = min(시가, 종가) - 저가`로 계산하며, ORB 구간 내 꼬리 비중을 통해 상단 저항과 하단 지지의 흔적을 판단
- [x] 윗꼬리/아랫꼬리 구조 비교 후보값: ORB 구간 전체 `윗꼬리 합 / 전체 레인지 합`, `아랫꼬리 합 / 전체 레인지 합` 기준 `0.2 / 0.3 / 0.4`
- [x] 윗꼬리/아랫꼬리 구조는 `보조 파라미터`로 취급

- [x] 봉 간 중첩도: 연속된 두 봉의 겹침 구간을 `max(0, min(현재봉 고가, 이전봉 고가) - max(현재봉 저가, 이전봉 저가))`로 계산하고, ORB 구간 전체 겹침 합을 통해 박스권 횡보 성격인지 계단식 추세 형성인지 판단
- [x] 봉 간 중첩도 비교 후보값: ORB 구간 전체 `연속 봉 겹침 구간 합 / 전체 레인지 합` 기준 `0.2 / 0.4 / 0.6`
- [x] 봉 간 중첩도는 `보조 파라미터`로 취급

- [x] ORB 형성 중 거래량 구조: `ORB 후반부 초당 평균 거래량 / ORB 전반부 초당 평균 거래량`으로 계산하며, ORB 형성 과정에서 거래량이 식는지 유지되는지, 또는 오히려 강화되는지를 판단
- [x] ORB 형성 중 거래량 구조 비교 후보값: `0.8 / 1.0 / 1.2`
- [x] ORB 형성 중 거래량 구조는 `핵심 파라미터`로 취급

#### 1.4.2 돌파 확인 구간

- [x] 돌파 확인 구간은 별도 파라미터로 관리
- [x] 비교 후보 구간: `10초 / 30초 / 1분`
- [x] 확인 구간은 `최초 돌파 시점부터의 경과 시간` 기준으로 계산
- [x] 돌파 확인 구간에 따라 사용 가능한 지표가 달라진다고 명시

- [x] 확인 구간 종료 초과폭: `(확인 구간 종료가 - ORB High) / (ORB High - ORB Low)`로 계산하며, 확인 구간 종료 시 가격이 ORB High 위에서 얼마나 확실하게 마감했는지 ORB 폭 대비 비율로 판단
- [x] 확인 구간 종료 초과폭 비교 후보값: `0.0 / 0.1 / 0.2`
- [x] 확인 구간 종료 초과폭은 `핵심 파라미터`로 취급
- [x] 거래량 비율: `확인 구간 초당 평균 거래량 / ORB 구간 초당 평균 거래량`으로 계산하며, `10초 / 30초 / 1분` 구간을 공정하게 비교하기 위해 시간 정규화된 비율을 사용
- [x] 거래량 비율 비교 후보값: `1.0 / 1.5 / 2.0`
- [x] 거래량 비율은 `핵심 파라미터`로 취급

- [x] ORB High 상단 유지 비율: `확인 구간 내 마지막 체결가가 ORB High를 초과한 상태로 머문 시간 / 확인 구간 전체 시간`으로 계산하며, 돌파 직후 가격이 상단에서 실제로 버텼는지 판단
- [x] ORB High 상단 유지 비율 비교 후보값: `0.6 / 0.7 / 0.8`
- [x] ORB High 상단 유지 비율은 `핵심 파라미터`로 취급

- [x] 돌파 구간 최대 되밀림: `max(0, ORB High - 확인 구간 내 최저가) / (ORB High - ORB Low)`로 계산하며, 돌파 후 ORB High 아래로 되밀린 정도를 ORB 폭 대비 비율로 측정
- [x] 돌파 구간 최대 되밀림 비교 후보값: `0.0 / 0.1 / 0.2`
- [x] 돌파 구간 최대 되밀림은 `핵심 파라미터`로 취급

#### 1.4.3 과열/비정상 상태

- VI 발동/근접 여부: ORB 형성 또는 돌파 구간에서 VI 위험이 있으면 신호 품질 저하 또는 제외 대상으로 볼지 판단

### 1.5 진입 조건

#### 1.5.1 본전략 진입 조건

- [x] 본전략은 `확인된 돌파 신호 이후 실행 방식 비교`로 정의
- [x] 확인 완료 이전 가격으로 소급 진입하지 않고, 확인 시점 이후 가격으로만 진입 처리
- [x] 주문 생성 시점과 실제 체결 가격은 분리해서 다루며, 실제 체결은 `1.10 체결 가정`에서 결정

- [x] 실행 방식 후보 1: 확인 구간 종료 후 주문 생성
- [x] 실행 방식 후보 2: 확인 후 첫 눌림목 시 주문 생성
- [x] 눌림목 진입은 `눌림 판단 시그널` 정의 전까지 후순위 탐색 후보로 관리

- 동일 종목 재진입 허용 여부는 별도 운영 규칙에서 결정
- 주문 방식(지정가/시장가/조건부)은 별도 체결 가정에서 결정

#### 1.5.2 눌림 판단 시그널

- [x] 눌림 판단 시그널은 `확인된 돌파 이후의 2차 진입 신호`로 별도 관리
- [x] `ORB High`는 눌림의 실패/구조 훼손 기준 레벨로 사용
- [x] 눌림 깊이 자체는 `확인 구간 종료가` 또는 `돌파 후 형성된 단기 고점` 대비 되돌림으로 별도 판단

- 구조 훼손 허용 이탈폭: `max(0, ORB High - 눌림 구간 최저가) / (ORB High - ORB Low)`로 계산하며, 눌림 과정에서 ORB High 아래로 어느 정도까지 이탈을 허용할지 판단
- 구조 훼손 허용 이탈폭 비교 후보값: `0.0 / 0.05 / 0.1`
- 구조 훼손 허용 이탈폭은 `핵심 파라미터 후보`로 취급

- 눌림 깊이 비율: `(기준 고점 - 눌림 구간 최저가) / (기준 고점 - ORB High)`로 계산하며, 기준 고점은 `확인 구간 종료가` 또는 `돌파 후 단기 고점` 중 하나로 추후 확정
- 눌림 깊이 비율 비교 후보값: `0.3 / 0.5 / 0.7`
- 눌림 깊이 비율은 `핵심 파라미터 후보`로 취급

- 눌림 지속 시간: 확인 완료 후 눌림 시작부터 주문 생성 신호 발생 전까지의 경과 시간으로 정의
- 눌림 지속 시간 비교 후보값: `10초 / 30초 / 1분`
- 눌림 지속 시간은 `보조 파라미터 후보`로 취급

- 눌림 종료 후 주문 생성 신호: 눌림 종료를 어떤 방식으로 확인할지 별도 정의 필요
- 주문 생성 신호 후보 1: ORB High 재상향 돌파

## 2. 백테스트 비교 원칙

아래 항목들은 ORB 시간 외에는 최대한 동일하게 유지한다.

- 거래 시간대
- 종목 유니버스

- 슬리피지/수수료/세금

- 청산 방식
- 재진입 허용 여부
- 일일 손실 제한

검증 목적:

- 어느 ORB 길이가 KRX 오프닝 구간에서 가장 안정적인 기대값을 만드는지 확인
- 짧은 ORB가 노이즈에 취약한지 확인
- 긴 ORB가 진입 지연과 손절폭 확대를 유발하는지 확인

## 3. 현재 합의된 방향

- 목표는 코드를 먼저 짜는 것이 아니라 ORB 전략의 비즈니스 로직과 가설을 확정하는 것이다.
- ORB의 고정 시간값을 먼저 정답처럼 두지 않는다.
- `3분 / 5분 / 10분 / 15분` ORB를 각각 별도 조건으로 백테스트하여 비교한다.
- 각 ORB 시간대별로 기대값, 체결 품질, 손익 구조를 나란히 비교한다.

## 4. 핵심 원칙

- `왜 5분인가`를 먼저 가정하지 않는다.
- ORB 시간은 연구 대상이며, 백테스트로 검증한다.
- 같은 청산 규칙, 같은 비용 가정, 같은 종목 선정 규칙 위에서 ORB 시간만 바꿔 비교해야 한다.
- 필터를 너무 많이 붙이기 전에 최소 전략을 먼저 고정한다.
