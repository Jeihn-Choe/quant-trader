# 백테스트 구조 메모

## 왜 이렇게 나눴는가

`02.백테스트프로그램정의.md`는 완성형 실거래 시스템이 아니라
연구 우선 백테스트를 요구합니다.
그래서 1차 진단 기능은 작게 유지하면서 이후 필터를 붙이기 쉽게 분리했습니다.

## 계층

- `quant_trader.config`: TOML 실행 파라미터 로드
- `quant_trader.io`: 원본 CSV 입력과 결과 CSV 출력
- `quant_trader.backtest`: ORB 연구 로직
- `quant_trader.ui`: 표시 전용 계층, 현재는 콘솔 요약만 포함

## 현재 흐름

1. CSV에서 분봉과 선택적 틱 데이터를 읽습니다.
2. 종목별, 거래일별 세션으로 묶습니다.
3. 설정된 ORB 구간마다 반복합니다.
4. ORB High와 ORB Low를 계산합니다.
5. 갭상승 여부를 판단합니다.
6. 갭상승이면 첫 ORB High 돌파를 찾습니다.
7. 돌파가 있으면 확인 구간과 10:00까지 유지율을 계산합니다.
8. 비교용 평면 결과 행으로 내보냅니다.

## 결과 스키마

각 결과 행에는 정의 문서에서 요구한 최소 출력이 들어갑니다.

- 종목코드와 거래일
- 갭상승 여부
- ORB 구간, ORB High, ORB Low
- 돌파 여부, 최초 돌파 시각, 가격, 초과폭
- 10:00 가격과 ORB High 상회 여부
- 10:00까지 유지 비율
- `confirm_10s` 같은 확인 구간 컬럼

## 확장 포인트

- 돌파 탐지 전에 세션 필터를 더 추가할 수 있습니다.
- 엔진 코드를 바꾸지 않고 더 풍부한 데이터 공급자를 붙일 수 있습니다.
- 결과 행 위에 UI나 대시보드를 올릴 수 있습니다.
- 눌림, 거래량, 청산 규칙 같은 지표를 확장할 수 있습니다.
